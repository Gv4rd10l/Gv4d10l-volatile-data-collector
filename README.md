# Gv4d10l-volatile-data-collector

A bash script tool to collect data from volatile memory on Linux.

## Before You Use the Tool

Follow these steps before using the script:

1. Open the `.sh` file with your preferred text editor.
2. Locate the third line in the script:

   ```bash
   OUTPUT_DIR="/media/usb/volatile_data"

3. Replace the default path /media/usb/volatile_data with the desired path where you want to store the captured data. For example:

   OUTPUT_DIR="/home/username/capture_data"
